== What this permits and what it does not claim

A dynamically supplied query within P2 can use the real LeanIO route while retaining
certificate-level tenant authorization through output encoding. The pure backend is a
proved implementation; effectful adapters must produce contract evidence. The batching
optimizer retains its response-preservation result under deterministic meanings and
its broader fault-safety result for permitted nondeterministic answers. Its cost result
counts Machine calls, not wall-clock time or physical network requests.

Parser and envelope source fidelity, external identity/acquisition/service refinement, native
execution and network delivery remain explicit trust boundaries. The concrete demo
uses an immutable in-memory snapshot and fixed test credentials. There is no production
database integration, concurrency/cancellation proof, delivery/liveness theorem,
complete GraphQL language support or general authorization theorem for arbitrary apps.
S7/S8 will extend the proved core; P3 features were not added in S6.
