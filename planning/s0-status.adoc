Authorization binds root lookups and relationships to exact selected occurrences,
requires ownership of domain objects, and fixes each leaf's parent and projection.
The query root and envelope have public structural rules. Erasure takes no snapshot
or principal. Errors use closed codes and selected-field/filtered-index paths.

The 78 tenant theorems include:

* Duplicate IDs, foreign-before-owned lookup, and first-owned occurrence selection.
* Rejection of real foreign members, copied-tenant forged records, wrong fields,
  wrong parents, and a real foreign occurrence used as a provenance label.
* Full authorization trees and conformance witnesses for success and both roadmap
  bubbling cases, on the adversarial fixture snapshot with cross-tenant edges.
* A nullable root becoming null and a non-null root list becoming `data: null`,
  preserving exactly one error and its original path at filtered task index zero.
* Successful sibling preservation, equal missing/foreign outcomes, and omission of
  foreign tasks even when they refer to owned projects.
* Rejection of full trees with forged or wrong-parent scalars, and rejection by
  `EvalSpec` of spurious Unavailable errors even outside the success hypotheses.

== Scope and review resolution

F1 from the initial review is replaced by an actual occurrence-label rejection;
F2 has real-foreign-member and wrong-parent fixtures. N1 is handled by occurrence
lookup with first-match/value proofs, and N3 by explicit list/nullability shapes.

P1 accepts string ID literals only; integer ID coercion is a declared restriction.
Child authorization requires an owned parent. A decidable surface validator remains
S1/S5 work. Malformed syntax has a total reference interpretation, but application
guarantees require `ValidOperation`.

Framework argument, exhaustion, and internal failures have prescribed paths and
nullability in the authorization rules. Pure valid reference evaluation has no fuel
or injected faults. Equality with that specification cannot invent public failures.

`SuccessConditions` lists validity, unique IDs, owned root targets, and owned required
relationship targets. These are not safety premises. Universal execution preservation
and IR correspondence remain S1/S4 work. S0 does not prove the existing runtime correct.
Authorization describes permitted derivations, not causal reads, implicit flows,
timing, logs, or output noninterference; the future view theorem remains separate.
